cognitive load, flow, walkthrough), then fixes. Four read-only code audits

browser walkthrough of the first-run journey on an isolated local stack.

## Fixed (highlights, by severity)
**Sev 4**
- Page titles, subtitles and header actions were invisible (GSAP `from` tween
  stuck at opacity 0). `PageHeader`/`Reveal` now use a CSS `.ui-reveal` keyframe.
- Home, Goals, Snapshots: failed `/goal-specs`, `/goal-inputs`, `/snapshots`
  fetches spun forever → error card + Retry. `/` and post-onboarding "Loading…"
  forever on hub fetch failure → error card + Retry/Sign out; hubs refetch after
  onboarding.
- Waiting-approval never released the user after approval → polls every 30s,
  "Check again", redirects when active.
- "Save & re-analyze", analyst "Save all" and "Build my own" silently deleted all
  logged history → Cancel added, confirm names the N entries, history is only
  wiped when the tracker shape changes; analyst no longer deletes specs before a
  run.
- Stepper Save dropped journal / before-after drafts; drafts leaked between
  windows → draft flush registry, `key` per window, dirty confirms.
- Goals editor PUT on every keystroke with silent 409 rollbacks → 600ms
  coalesced save + "Your last edit didn't save" banner.
- Fill modal on the home hero vanished mid-task when the queue reordered → modal
  state lifted.

## Second pass — closing the open items
- **2FA backup codes**: 10 single-use codes shown once at enrolment (copy /
  download), "Use a backup code instead" at sign-in, "N left" + "Generate new
  codes" in Account, cleared by admin reset / `admin:reset-totp` (script was
  missing — now exists). Users with zero codes get a sign-in warning.
- **Last graded**: AI tier verdicts now return `gradedAt`, so the ladder shows
  "Last graded X ago" for AI grades too.
- **Approver named**: submit-for-approval returns the manager's name; with no
  manager it says it was auto-approved and why, instead of implying review.
- **Criteria-changed notifications** open the recipient's own affected goal;
  deleting a policy now notifies too.
- **Navigation**: the vertical side tabs are replaced by a horizontal
  sub-nav (Overview · Reviews log · Snapshots · Shared with me); "Shared with
  me" is also in the account menu; goals assigned by a manager read
  "Assigned", not "Shared".
- **Analyst overlay**: focus trap, Escape, focus returns to the opener.
- **Found in the headless walkthrough and fixed**: pages scrolled sideways on
  phones (segmented controls, range bar, page-header actions); phone header
  truncated the wordmark to "e…"; the login form navigated during render; the
  goals editor nested a button in a button; five links wrapped a button
  (Button now takes `as={Link}`); the counter showed a lifetime total next to
  this week's count; targets printed ">=" instead of "≥".

## Still open / needs a decision
- **Weekly windows run Thursday–Wednesday** in 2026 because they are counted
  from 1 January (`packages/shared/src/goal-specs/windows.js`). Aligning them
  to a work week changes which window existing entries fall in for grading,
  snapshots and shared-goal analytics.
- **A tracker set up mid-year is immediately "Behind"**: every earlier week
  of the calendar-year cycle counts as missed. Options: start the cycle at the
  tracker's creation (or hire date), or keep it and lean on backfill.
- Moving 2FA to a new phone still needs an admin (disable requires a current
  code).
- Manager-hub gaps from `docs/hub-audit.md` were out of scope.
